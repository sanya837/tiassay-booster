# 🚀 GAME BOOSTER & LAUNCHER v2.2

Стильный системный оптимизатор оперативной памяти для геймеров. Очищает скрытый кэш Windows и разгоняет систему перед каткой.

## 👑 Разработчик
* **Автор:** tiassay
* **Профиль:** [guns.lol/tiassay](https://guns.lol/tiassay)

## 🎮 Поддерживаемые игры
* **CS2** & **Dota 2** & **Rust** (через Steam)
* **Valorant** (Riot Client)
* **Fortnite** (Epic Games)

## ⚡ Как запустить
1. Скачайте `GAMEBOOSTER.exe` из вкладки **Releases**
2. Нажмите правой кнопкой мыши -> **Запуск от имени администратора** (важно для глубокой очистки памяти).
3. Выберите цифру вашей игры и нажмите **Enter**.
